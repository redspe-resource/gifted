while 迴圈：不知道幾次的時候

第 8 週｜教師講義版

while 迴圈校園闖關點數計算器（七）

上週的 for 迴圈有個前提：先知道要做幾圈。這一週反過來——想玩幾關就玩幾關，程式自己等到結束訊號出現才停。

1認識 while 迴圈

條件成立就一直做，做到不成立為止。

2學會哨兵值

用 -1 當「結束訊號」，不是點數。

3讀兩次的模式

進迴圈前讀一次、迴圈裡再讀一次。

4條件要會變

條件裡的變數，每圈都要換新值。

為什麼重要：真實的程式常常「不知道會輸入幾個」——問卷、遊戲、感測器都是。while 是這種情況的標準工具。

操作：底部按鈕或鍵盤 ← → 翻頁；手機可左右滑動；內容過長時在當頁向下捲動。

備課與帶領：0–2 分鐘。開場對比：上週迴圈「知道幾圈」，這週迴圈「做到訊號出現」。新語法只有 while 那一行，難的是讀兩次的模式。

回顧

先回顧：你還記得嗎？

第七週用 for 迴圈讀三關：

C++
int points;
int taskPoints = 0;
for (int i = 1; i <= 3; i++) {
    cin >> points;
    taskPoints = taskPoints + points;
}

問題一：輸入 20 25 18，taskPoints 是多少？

核對答案

63。迴圈跑 3 圈，0 → 20 → 45 → 63。

問題二：如果今天不知道有幾關——想玩幾關玩幾關——for 迴圈卡在哪裡？

核對答案

for 要先寫好 i <= 3，一定要先知道幾圈。關卡數不固定時，我們需要「做到訊號出現為止」的迴圈。

備課與帶領：0–5 分鐘。回顧 for 版，直接問「不知道有幾關怎麼辦」。讓學生卡一下——這個卡點就是本週的動機。

新概念

while 迴圈與哨兵值

while 的規則比 for 更簡單：條件成立就做，做完再檢查一次，直到不成立。

C++
cin >> points;                       // 先讀一次
while (points != -1) {              // 不是訊號，就做
    taskPoints = taskPoints + points;
    cin >> points;                   // 讀下一個
}
  • 哨兵值 -1：它不是點數，是「我玩完了」的訊號。跟 i 一樣，是「不是資料的資料」。
  • 為什麼要先讀一次？條件第一次檢查時，points 要已經有值。迴圈結束前再讀一次，拿下一個輸入來更新條件。
  • 條件裡的變數必須變：points 每圈都換新值。如果條件裡的變數永遠不變，迴圈永遠不會停。
讀兩次，是 while 最容易錯的地方：進迴圈前一次、迴圈裡一次。兩個 cin，一個都不能少。
備課與帶領：5–10 分鐘。while 結構＋哨兵值。強調 -1 是「不是資料的資料」，跟 i 是計數器同一族概念。「讀兩次」在黑板標出兩個 cin。

對照

for vs while，同一件事

第七週：for（固定 3 關）
int points;
int taskPoints = 0;
for (int i = 1; i <= 3; i++) {
    cin >> points;
    taskPoints = taskPoints
        + points;
}
本週：while（-1 結束）
int points;
int taskPoints = 0;
cin >> points;
while (points != -1) {
    taskPoints = taskPoints
        + points;
    cin >> points;
}
  • for：計數器 i 掌控一切，圈數寫在第一行。
  • while：沒有 i、沒有圈數——「什麼時候停」交給輸入的 -1 決定。
兩個 cin 是關鍵差別：for 版 cin 在迴圈裡一個就夠；while 版要「先讀、再做、再讀」。
備課與帶領：10–14 分鐘。並排對照。讓學生指出：哪裡多一行、哪裡少了 i。問：兩個 cin 各自的工作是什麼？

核心觀念

追蹤：輸入 20 25 18 -1

跟著 points 一步一步走：

while 條件的四次檢查
檢查 1：points = 20，20 != -1成立 → 加總 0→20，再讀到 25
檢查 2：points = 25，25 != -1成立 → 加總 20→45，再讀到 18
檢查 3：points = 18，18 != -1成立 → 加總 45→63，再讀到 -1
檢查 4：points = -1，-1 != -1不成立 → 離開迴圈
想一想：-1 被加進 taskPoints 了嗎？
沒有。迴圈先檢查再加總——-1 在檢查時就被擋在門外，根本進不了加總那行。
備課與帶領：14–18 分鐘。追蹤 20 25 18 -1，重點放在第四次檢查——-1 在門口就被擋下。要聽到「條件裡的變數每圈換新值」。

示範

完整程式：開啟、儲存、執行

  1. 開啟上週已能執行的 Code::Blocks 專案。
  2. 先將 main.cpp 另存備份，再用下方程式完整取代內容，不要出現兩個 main()。
  3. 按 F9（Build and run）。
  4. 輸入 30 30 30 -1，按 Enter；總點數 95，預期印出「金牌」——和以前一樣。
C++
#include <iostream>
using namespace std;

int main() {
    int points;
    int taskPoints = 0;

    cin >> points;
    while (points != -1) {
        taskPoints = taskPoints + points;
        cin >> points;
    }

    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= 60) {
        if (totalPoints >= 90) {
            cout << "金牌" << endl;
        } else {
            cout << "銀牌" << endl;
        }
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
畫面沒有反應？

游標正在等待時，輸入點數，最後加上 -1，中間用空格分開，再按 Enter。若程式一直不動，檢查迴圈裡的 cin——少了它就會變成無窮迴圈。

備課與帶領：18–21 分鐘。示範 30 30 30 -1 → 金牌。提醒輸入最後一定要 -1，否則程式會一直等。

必做

必做：換成 while 版

任務：把讀取部分換成 while 迴圈＋哨兵值 -1。計算和分級一行都不用改，輸出必須完全不變。

輸入：30 30 30 -1　輸出：金牌
輸入：20 25 18 -1　輸出：銀牌（總點數 68）
輸入：10 12 9 -1　輸出：未過關（總點數 36）
提示：要改哪裡？

把 for 那段刪掉，換成「先讀、while、加總、再讀」。口訣：先讀一次進迴圈，加總之後再讀一次。兩個 cin，一個都不能少。

C++
#include <iostream>

挑戰

挑戰：印出共玩了幾關

新任務（選做）：程式最後多印一行「共 X 關」。while 沒有 i 幫你數——自己放一個計數器進去。

輸入：30 30 30 -1　輸出：共 3 關　金牌
輸入：20 20 20 20 -1　輸出：共 4 關　銀牌（總點數 85）
輸入：12 -1　輸出：共 1 關　未過關（總點數 17）
提示

宣告 int roundCount = 0;，在迴圈裡加總之後放一行 roundCount = roundCount + 1;。離開迴圈後，先用 cout 印出它，再印分級結果。

核對參考程式
C++
#include <iostream>
using namespace std;

int main() {
    int points;
    int taskPoints = 0;
    int roundCount = 0;

    cin >> points;
    while (points != -1) {
        taskPoints = taskPoints + points;
        roundCount = roundCount + 1;
        cin >> points;
    }

    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    cout << "共 " << roundCount << " 關" << endl;

    if (totalPoints >= 60) {
        if (totalPoints >= 90) {
            cout << "金牌" << endl;
        } else {
            cout << "銀牌" << endl;
        }
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
看出來了嗎？for 迴圈的 i，原來就是一個自動幫你加一的計數器——你剛剛用手動把它做出來了。
備課與帶領：選做。roundCount 計數器。做完追問：「for 的 i 是什麼？」——讓學生自己說出「自動加一的計數器」，兩週正式接軌。

除錯

條件寫錯了：0 關卡提前結束

C++
cin >> points;
while (points > 0) {
    taskPoints = taskPoints + points;
    cin >> points;
}

輸入 30 0 30 -1（預期總點數 65、銀牌），畫面印出「未過關」。哪裡錯了？

顯示修正與原因

條件寫成 points > 0，0 也被當成訊號了。第 2 個輸入是 0，不大於 0，迴圈提前結束：只加到 30，總點數 35 → 未過關。

修正：條件改回 points != -1。口訣：哨兵是什麼，條件就檢查什麼——用 -1 當結束訊號，就檢查 != -1。0 是正常的點數，別讓它誤觸結束。

另一個更危險的錯：迴圈裡忘了 cin >> points;，points 永遠不變，條件永遠成立——無窮迴圈。上週說過「條件永遠成立會停不下來」，這週你知道成因了：條件裡的變數沒有被更新。關掉視窗，補上 cin。
備課與帶領：36–38 分鐘。先預測 30 0 30 -1 在 points > 0 版的結果再執行。無窮迴圈成因這週講透：條件變數沒更新。
