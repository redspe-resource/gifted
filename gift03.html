第 3 週｜學生使用版

開啟、儲存、執行

  1. 開啟上週已能執行的 Code::Blocks 專案。
  2. 將專案中的 main.cpp 內容另存備份，再修改目前的 main.cpp。
  3. 用下方程式完整取代原有內容，不要重複貼出兩個 main()。
  4. 儲存後，按 F9，或選 Build → Build and run。
  5. 在執行視窗輸入 12 9，按 Enter；預期得到 26。
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints;
    cin >> firstPoints >> secondPoints;

    int taskPoints = firstPoints + secondPoints;
    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    cout << totalPoints << endl;
    return 0;
}
畫面沒有答案？

游標正在等待時，請在執行視窗輸入兩個整數，中間用空格分開，再按 Enter。若無法編譯，先看 Build messages 的第一個錯誤，不要只按 Run 執行舊程式。

第 3 週｜學生使用版

必做：三項任務加獎勵

依序輸入三項任務點數，每項為 0 到 100 的整數。完成後固定加 5 點，輸出最後總點數。

輸入：12 9 15
輸出：41

保留 taskPoints、bonusPoints、totalPoints。新增 thirdPoints，修改讀入與小計兩個步驟。

提示：哪些地方要改？

新增第三個變數，cin 多讀一個數字，taskPoints 加入第三项點數；最後輸出仍是 totalPoints。

完成後核對參考程式
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints, thirdPoints;
    cin >> firstPoints >> secondPoints >> thirdPoints;

    int taskPoints = firstPoints + secondPoints + thirdPoints;
    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    cout << totalPoints << endl;
    return 0;
}

挑戰：獎勵也由你輸入

提示

bonusPoints 改成輸入變數。刪除固定設定 int bonusPoints = 5;，避免重複宣告。

核對參考程式
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints, thirdPoints, bonusPoints;
    cin >> firstPoints >> secondPoints >> thirdPoints >> bonusPoints;

    int taskPoints = firstPoints + secondPoints + thirdPoints;
    int totalPoints = taskPoints + bonusPoints;

    cout << totalPoints << endl;
    return 0;
}
