回顧

先回顧：你還記得嗎？

第三週的程式，最後三行是這樣：

C++
int taskPoints = firstPoints + secondPoints + thirdPoints;
int bonusPoints = 5;
int totalPoints = taskPoints + bonusPoints;

問題一：輸入 12 9 15，最後 totalPoints 是多少？

核對答案

41。任務小計 12 + 9 + 15 = 36，加上固定獎勵 5，得到 41。

問題二：taskPoints 和 totalPoints 有什麼不同？

核對答案

taskPoints 是三項任務的小計；totalPoints 是加上獎勵後的最後總點數，也是要拿去判斷的數字。

備課與帶領：0–4 分鐘。請學生先預測 41 再公佈。若多數人已忘記 taskPoints 與 totalPoints 的差別，先帶一組手算再前進。

新規則

本週新規則：達 60 點，才算過關

校園闖關新增一條規則：最後總點數達到 60（含 60），闖關成功。

68過關68 達到 60 以上
41未過關41 未達 60
注意：獎勵仍然固定加 5 點，本週新增的只有「判斷」。順序是：先加獎勵，得到 totalPoints，再判斷過不過關。

用 IPO 看這一週的任務：

Input 輸入Process 處理Output 輸出
三項任務點數，讀進三個變數三項相加 → 加 5 點獎勵 → 和門檻 60 比較印出「過關」或「未過關」
不要誤會：不是「達標才有獎勵」。獎勵照加，判斷在後面。
備課與帶領：4–8 分鐘。最常見誤解是「達標才有獎勵」，要出聲導正：先加獎勵、再判斷。可舉及格分數 60 分類比。

新符號

比較符號：>= 是什麼意思？

>= 讀作「大於或等於」。拿總點數和門檻 60 比大小：

575859未過關
60門檻
616275過關
符號讀作哪些數字算例子（門檻 60）
>=大於或等於60、61、62……60 算、59 不算
>大於61、62、63……60 不算
<=小於或等於60、59、58……認識即可
記住：> 和 >= 只差一個等號，結果可能完全不同。本週先用 >=。
備課與帶領：8–11 分鐘。讓全班唸三次：59 不算、60 算、61 算。本頁只要記住 >=，其他符號看過就好。

新語法

程式的新部分：if / else

在 totalPoints 算完之後，加上這四行：

C++
if (totalPoints >= 60) {
    cout << "過關" << endl;
} else {
    cout << "未過關" << endl;
}
totalPoints >= 60
條件成立
印出「過關」
條件不成立
印出「未過關」
  • if 是「如果」：條件成立，就執行它大括號 { } 裡的事。
  • else 是「否則」：條件不成立，就執行它大括號裡的事。
記住：兩個大括號裡的程式，每次執行只會走其中一邊。
備課與帶領：11–14 分鐘。if＝如果、else＝否則，用「岔路只走一邊」比喻。大括號裡是「要做的事」。

示範

完整程式：開啟、儲存、執行

  1. 開啟上週已能執行的 Code::Blocks 專案。
  2. 先將 main.cpp 另存備份，再用下方程式完整取代內容，不要出現兩個 main()。
  3. 按 F9（Build and run）。
  4. 輸入 20 25 18，按 Enter；總點數 68，預期印出「過關」。
C++
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints, thirdPoints;
    cin >> firstPoints >> secondPoints >> thirdPoints;

    int taskPoints = firstPoints + secondPoints + thirdPoints;
    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= 60) {
        cout << "過關" << endl;
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
畫面沒有反應？

備課與帶領：14–17 分鐘。沿用上週專案，避免重花時間建置。確認學生不是另開新檔卻仍執行舊專案。示範輸入 20 25 18 → 印出過關。

挑戰

挑戰：門檻也由你輸入

輸入三項任務點數和門檻（四個整數，都在 0 到 100 之間），輸出「過關」或「未過關」。

輸入：12 9 15 35　輸出：過關（總點數 41 ≥ 門檻 35）
輸入：12 9 15 60　輸出：未過關（總點數 41 < 門檻 60）
提示

新增變數 thresholdPoints，讓 cin 多讀一個數字，判斷改成 if (totalPoints >= thresholdPoints)。門檻不再是固定的 60。

核對參考程式
C++
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints, thirdPoints, thresholdPoints;
    cin >> firstPoints >> secondPoints >> thirdPoints >> thresholdPoints;

    int taskPoints = firstPoints + secondPoints + thirdPoints;
    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= thresholdPoints) {
        cout << "過關" << endl;
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
備課與帶領：選做，不是全班進度。需要新增變數、cin 多讀一個數字，並把 60 換成 thresholdPoints。先寫 IPO 再動手。

除錯

剛好 60，卻說未過關？

C++
int taskPoints = firstPoints + secondPoints + thirdPoints;
int bonusPoints = 5;
int totalPoints = taskPoints + bonusPoints;

if (totalPoints > 60) {
    cout << "過關" << endl;
} else {
    cout << "未過關" << endl;
}

輸入 18 18 19，總點數剛好 60，畫面卻印出「未過關」。程式能執行，哪裡錯了？

顯示修正與原因

判斷用了 >（大於），60 本身不包含在內，所以 60 落到 else。改成 >=（大於或等於），60 就會過關。

C++
if (totalPoints >= 60) {
這種錯最危險：程式能編譯、能執行，只是結果和題目不同。要比對 59、60、61 三組資料才找得到。
備課與帶領：33–37 分鐘。區分「可執行但結果不符題目」。讓學生口頭說出 > 與 >= 的差別，再自己改掉那一行。
