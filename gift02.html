變數：有名字的資料位置

firstPoints

記住第一項任務的點數。

secondPoints

記住第二項任務的點數。

totalPoints

記住兩項任務加起來的總點數。

記住：變數名稱要讓人看得出它存的是什麼資料。
先看變數怎麼工作

先用固定點數寫一次

#include <iostream>
using namespace std;

int main() {
    int firstPoints = 12;
    int secondPoints = 9;
    int totalPoints = firstPoints + secondPoints;

    cout << totalPoints << endl;
    return 0;
}
int firstPoints = 12;建立一個整數變數，名稱是 firstPoints，裡面放 12。
int secondPoints = 9;建立一個整數變數，名稱是 secondPoints，裡面放 9。
int totalPoints = firstPoints + secondPoints;先算右邊，再把結果放進 totalPoints。
資料在程式裡的變化

輸入 12 與 9 時

變數名稱目前的值它代表什麼？
firstPoints12第一項任務點數
secondPoints9第二項任務點數
totalPoints21兩項任務的總點數
預測：如果 firstPoints = 20，secondPoints = 5，最後輸出什麼？先寫下答案，再執行確認。
讓每次輸入的點數都不同

使用 cin 讀入點數

#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints;
    cin >> firstPoints >> secondPoints;

    int totalPoints = firstPoints + secondPoints;

    cout << totalPoints << endl;
    return 0;
}

cin 的工作

讀入資料。

第一個數字放進 firstPoints。

第二個數字放進 secondPoints。

cout 的工作

輸出資料。

cout << totalPoints 會輸出總點數。

測試程式

#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints;
    cin >> firstPoints >> secondPoints;

    int totalPoints = firstPoints + thirdPoints;

找錯：哪一個變數沒有被建立？哪一個變數名稱少了一個字母？

錯誤 1：thirdPoints 沒有被建立；這裡應該使用 secondPoints。

錯誤 2：totalPoint 少了 s；正確是 totalPoints。
