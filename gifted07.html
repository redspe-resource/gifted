for 迴圈：讓程式自己重複

第 7 週｜教師講義版

for 迴圈校園闖關點數計算器（六）

又是「結果不變、寫法改變」：三個變數讀三關，換成讓程式自己重複三次。這是第一次，程式會「自己重來」。

1認識 for 迴圈

讓程式自己重複做同一件事。

2看懂三件事

從哪開始、做到什麼時候、每圈結束做什麼。

3學會累加器

taskPoints 先歸零，再一圈一圈加上去。

4只改一個數字

三關變五關，迴圈的威力。

為什麼重要：如果闖關有 100 關，總不能宣告 100 個變數。迴圈讓「重複」變得簡單。

操作：底部按鈕或鍵盤 ← → 翻頁；手機可左右滑動；內容過長時在當頁向下捲動。

備課與帶領：0–2 分鐘。開場就定位：本週又是「結果不變、寫法改變」，新語法只有 for 那一行。跟學生預告「今天程式會自己重來」。

回顧

先回顧：你還記得嗎？

我們已經連續四週這樣讀三關：

C++
int firstPoints, secondPoints, thirdPoints;
cin >> firstPoints >> secondPoints >> thirdPoints;

int taskPoints = firstPoints + secondPoints + thirdPoints;

問題一：輸入 20 25 18，taskPoints 是多少？

核對答案

20 + 25 + 18 = 63。

問題二：這幾行程式，哪裡讓你感覺「一直重複」？

核對答案

「讀一個數字、把它加起來」這件事做了三次，只有變數名稱不一樣。

備課與帶領：0–5 分鐘。回顧三變數版。問「哪裡感覺重複」，要聽到「讀三次、加三次」。沒人說出來就帶著逐行念一次。

新概念

for 迴圈三件事

把「讀一個數、加起來」交給程式自己重複。全部的秘密在這一行：

C++
for (int i = 1; i <= 3; i++) {
    // 這裡的程式，會做 3 次
}
① 起始：從哪開始int i = 1

i 是計數器，從 1 開始數

② 條件：做到何時i <= 3

成立才做這一圈

③ 更新：每圈結束i++

i 加 1，準備下一圈

  • i 不是點數，是拿來數「現在是第幾圈」。
  • i++ 是新語法，意思就是 i = i + 1。
  • i 數到 4，條件 i <= 3 不成立，迴圈結束。
迴圈裡面做什麼？讀一個數字，加到 taskPoints 上——就這麼簡單。
備課與帶領：5–10 分鐘。for 三件事逐一講：起始、條件、更新。i++ 等於 i = i + 1，用第六週已熟的「變數更新」解釋。taskPoints 歸零是本週伏筆，先點到。

對照

兩種寫法，同一個結果

舊版：三個變數
int firstPoints, secondPoints, thirdPoints;
cin >> firstPoints >> secondPoints >> thirdPoints;

int taskPoints = firstPoints
    + secondPoints + thirdPoints;
本週：迴圈
int points;
int taskPoints = 0;
for (int i = 1; i <= 3; i++) {
    cin >> points;
    taskPoints = taskPoints + points;
}
  • 舊版：三個變數，各讀一次、各加一次。
  • 新版：一個 points 重複用三次，taskPoints 一圈一圈加上去。
計算和判斷完全不用改：總點數、獎章分級跟以前一模一樣。
備課與帶領：10–14 分鐘。並排對照，讓學生自己指出「三個變數變兩個」。問：哪一邊要改成五關比較容易？

核心觀念

追蹤：taskPoints 一圈一圈長大

輸入 20 25 18，跟著迴圈走一遍：

迴圈追蹤：i 從 1 到 3
第 1 圈：i = 1，讀到 20taskPoints：0 → 20
第 2 圈：i = 2，讀到 25taskPoints：20 → 45
第 3 圈：i = 3，讀到 18taskPoints：45 → 63
第 4 次檢查：i = 4i <= 3 不成立 → 離開迴圈
想一想：taskPoints 為什麼一開始要設成 0？
這種變數叫「累加器」：從 0 開始，每圈加一點。忘了歸零，它一開始就不是 0，答案就會錯。
備課與帶領：14–18 分鐘。追蹤 20 25 18，在黑板逐圈寫 taskPoints 的變化。要聽到「累加」兩個字。追問：忘了歸零會怎樣？

示範

完整程式：開啟、儲存、執行

  1. 開啟上週已能執行的 Code::Blocks 專案。
  2. 先將 main.cpp 另存備份，再用下方程式完整取代內容，不要出現兩個 main()。
  3. 按 F9（Build and run）。
  4. 輸入 30 30 30，按 Enter；總點數 95，預期印出「金牌」——和上週一樣。
C++
#include <iostream>
using namespace std;

int main() {
    int points;
    int taskPoints = 0;
    for (int i = 1; i <= 3; i++) {
        cin >> points;
        taskPoints = taskPoints + points;
    }

    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= 60) {
        if (totalPoints >= 90) {
            cout << "金牌" << endl;
        } else {
            cout << "銀牌" << endl;
        }
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
畫面沒有反應？

游標正在等待時，輸入三個整數，中間用空格分開，再按 Enter。若無法編譯，先看 Build messages 的第一個錯誤——本週最常見的錯是 taskPoints 忘了設 0，或 for 那一行的分號打成冒號。

備課與帶領：18–21 分鐘。示範輸入 30 30 30 → 金牌。強調：判斷部分一行都沒改，只有讀取方式變了。

挑戰

挑戰：三關變五關

新任務（選做）：闖關改成五個關卡，要輸入五個點數。你只需要改一個數字。

輸入：20 20 20 20 20　輸出：金牌（總點數 105）
輸入：12 12 12 12 12　輸出：銀牌（總點數 65）
輸入：10 10 10 10 10　輸出：未過關（總點數 55）
提示

把 i <= 3 改成 i <= 5。其他通通不用動——這就是迴圈的威力。

C++
#include <iostream>

        cin >> points;
        taskPoints = taskPoints + points;
    }

    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= 60) {
        if (totalPoints >= 90) {
            cout << "金牌" << endl;
        } else {
            cout << "銀牌" << endl;
        }
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}
更厲害的：改成 10 關，輸入十個數字。你一共改了幾個字？
備課與帶領：選做。三關改五關只改一個數字，這是本週的「哇」時刻。讓先完成的學生示範給全班看，效果最好。

除錯

迴圈少跑一圈：印出奇怪的結果

C++
for (int i = 1; i < 3; i++) {
    cin >> points;
    taskPoints = taskPoints + points;
}

輸入 30 30 30，畫面印出「銀牌」，不是金牌。哪裡錯了？

顯示修正與原因

條件寫成 i < 3，迴圈只跑兩圈（i = 1、i = 2）：只讀到 30 和 30，第三個 30 還留在輸入區沒被讀走。taskPoints = 60，總點數 65 → 銀牌。

修正：條件改回 i <= 3。數圈數的口訣：1 到 3，共 3 圈；寫成 < 3 就只剩 2 圈。

另一個危險的錯：如果條件永遠成立（例如忘了寫 i++），迴圈永遠停不下來，這叫無窮迴圈。真的遇到了，直接關掉黑色視窗，再回來檢查 for 那一行。
備課與帶領：36–38 分鐘。先讓學生預測 30 30 30 在 i < 3 版印什麼，再執行。無窮迴圈只口頭警告，別讓全班真的跑。
