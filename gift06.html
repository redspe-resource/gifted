巢狀判斷：判斷裡面再判斷

第 6 週｜學生使用版

巢狀判斷校園闖關點數計算器（五）

這一週沒有新規則——結果和上週完全一樣。我們把同一件事換一種寫法：判斷的大括號裡面，再放一個判斷。

1認識巢狀判斷

大括號 { } 裡面，再放一個 if。

2比較兩種寫法

else if 排一排 vs 巢狀，輸出完全相同。

3配對大括號

每個 if 和 else 的大括號都要正確配對。

4記住 else 規則

else 只跟離它最近的 if 配對。

為什麼重要：有些規則本來就有「先決條件」——先過關，才分等級。巢狀寫法最貼近這種想法。

操作：底部按鈕或鍵盤 ← → 翻頁；手機可左右滑動；內容過長時在當頁向下捲動。

回顧

先回顧：你還記得嗎？

第五週的分級是用 else if 排成一排：

C++
if (totalPoints >= 90) {
    cout << "金牌" << endl;
} else if (totalPoints >= 60) {
    cout << "銀牌" << endl;
} else {
    cout << "未過關" << endl;
}

問題一：輸入 20 25 18，畫面印出什麼？

核對答案

總點數 68，印出「銀牌」。

問題二：else if 鏈是照什麼順序檢查的？

核對答案

由上往下檢查，第一個成立的條件贏，後面不再檢查。

新概念

巢狀判斷：大門與門內

把「過關」想成一扇大門：

  • 總點數 >= 60：進得了門。進門之後，門內再分等級——>= 90 金牌，否則銀牌。
  • 總點數未達 60：連門都進不去，直接印「未過關」。

寫成程式，就是大括號裡面再放一個 if：

C++
if (totalPoints >= 60) {
    if (totalPoints >= 90) {
        cout << "金牌" << endl;
    } else {
        cout << "銀牌" << endl;
    }
} else {
    cout << "未過關" << endl;
}
輸出和第五週一模一樣：同一件事，兩種寫法。

對照

兩種寫法，同一個結果

第五週：else if 排一排
if (totalPoints >= 90) {
    cout << "金牌" << endl;
} else if (totalPoints >= 60) {
    cout << "銀牌" << endl;
} else {
    cout << "未過關" << endl;
}
本週：巢狀——大門與門內
if (totalPoints >= 60) {
    if (totalPoints >= 90) {
        cout << "金牌" << endl;
    } else {
        cout << "銀牌" << endl;
    }
} else {
    cout << "未過關" << endl;
}
  • else if：條件排成一排，由上往下檢查，第一個成立的贏。
  • 巢狀：先過第一關（進門），才檢查第二關（分等級）。
兩種都對：同一種規則，挑一種好讀的寫。本週練習巢狀，之後你可以自己選。

核心觀念

追蹤：68 和 95 走巢狀路徑

追蹤一：總點數 68
68 >= 60 ?（大門）成立 → 進門，繼續檢查
68 >= 90 ?（門內）不成立 → 印「銀牌」
追蹤二：總點數 95
95 >= 60 ?（大門）成立 → 進門，繼續檢查
95 >= 90 ?（門內）成立 → 印「金牌」
想一想：巢狀版的銀牌寫在內層的 else。總點數 36 為什麼走不到這裡？因為它連大門（≥ 60）都沒過，整個區塊直接跳過。
記住：每次執行還是只印一個結果——大門走一邊，門內再走一邊。

挑戰

挑戰：榮譽金牌

新規則（選做）：過關者中，90–94 印「金牌」，95 以上印「榮譽金牌」——在金牌的大括號裡面，再放一層判斷。

輸入：30 30 30　輸出：榮譽金牌（總點數 95）
輸入：28 28 29　輸出：金牌（總點數 90）
輸入：20 25 18　輸出：銀牌（總點數 68）
提示

在印「金牌」的那個分支裡，再放一個 if (totalPoints >= 95)：成立印榮譽金牌，否則印金牌。這就是三層巢狀。

核對參考程式
C++
#include <iostream>
using namespace std;

int main() {
    int firstPoints, secondPoints, thirdPoints;
    cin >> firstPoints >> secondPoints >> thirdPoints;

    int taskPoints = firstPoints + secondPoints + thirdPoints;
    int bonusPoints = 5;
    int totalPoints = taskPoints + bonusPoints;

    if (totalPoints >= 60) {
        if (totalPoints >= 90) {
            if (totalPoints >= 95) {
                cout << "榮譽金牌" << endl;
            } else {
                cout << "金牌" << endl;
            }
        } else {
            cout << "銀牌" << endl;
        }
    } else {
        cout << "未過關" << endl;
    }
    return 0;
}

除錯

else 配錯了：印出奇怪的結果

C++
if (totalPoints >= 60) {
    if (totalPoints >= 90) {
        cout << "金牌" << endl;
    } else {
        cout << "未過關" << endl;
    }
}

輸入 20 25 18（總點數 68），畫面印出「未過關」，不是銀牌。輸入 10 12 9（總點數 36），畫面什麼都沒印。哪裡錯了？

顯示修正與原因

規則：else 只跟離它最近的 if 配對。這裡的 else 配到的是內層的 >= 90。68 過了大門、沒過門內這關，就掉進內層的 else 印「未過關」。36 連大門都沒過，整個區塊跳過，所以什麼都不印。

修正：銀牌要放在外層的 else：

C++
    } else {
        cout << "銀牌" << endl;
    }
} else {
    cout << "未過關" << endl;
}
巢狀最常見的錯：大括號配對跑掉。檢查方法——從最內層開始，每個 { 都往右縮排，關門的 } 要對齊它的 if。
